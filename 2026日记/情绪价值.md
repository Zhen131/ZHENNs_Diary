# 情绪价值

情绪价值指的是：一件东西、一段关系或一个体验，给人带来的开心、被安放、被陪伴、被点亮的感觉。

它不一定等于功能价值。功能价值会让人进入“有没有用、值不值、能不能替代”的比较模式；情绪价值更像一种直接的吸引力：我就是喜欢它，它让我开心，它让我愿意留下。

## 核心洞见

[[26_07_08 登机前的幸福与可乐]]里，Labubu 的例子让这个概念变得很清楚：如果一个玩偶被加上 U 盘功能，人反而会开始比较容量、速度和价格。功能越明确，越容易激活理性比价；而纯粹的玩偶可以只承载“我喜欢它”的情绪。

同一天，可乐也变成了一个生活里的小例子。要回云南之前，鸡翅、西瓜都可以清掉，但已经开封的可乐却还让人舍不得扔。它不只是饮料，也是一种熟悉的开心和习惯。

## 和反馈系统的关系

[[反馈系统]]不只是在记录事实，也在制造“我愿意继续回来”的感受。

GitHub 小绿块、账本系统里的趣味化模块、Labubu 玩偶、可乐带来的小开心，本质上都在提醒一件事：一个系统如果只追求正确和有用，可能仍然很难让人长期靠近。能让人愿意回来、愿意继续使用、愿意留下痕迹的，往往是功能之外的情绪反馈。
