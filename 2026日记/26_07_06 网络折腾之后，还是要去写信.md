# 网络折腾之后，还是要去写信

今天是 **2026年7月6日**，我在上海图书馆。

刚刚终于把网络配置好。现在是下午 **3:39**，但我从 **1:30** 左右就开始折腾，一直折腾到现在。说实话，整个人已经焦头烂额，身心俱疲。好不容易用上了 Codex，可今天真正要做的事还没开始。

这次主要有两个问题。

第一个是上海图书馆的公共网络连上以后不跳转验证页面。我到现在都说不清它是怎么被解决的。调系统时间，重启电脑，开着梯子重启，关着梯子重启，小红书上各种方法都试了一遍，最后稀里糊涂好了。它不是那种很清楚地“我做了 A，所以 B 好了”的问题，更像是一团乱麻里突然通了一下。

第二个问题更致命：小火箭用不了。

这个问题折腾了更久。后来在论坛上查到，大概率是 DNS 污染。最后用了这两条命令：

```bash
sudo dscacheutil -flushcache
sudo killall -HUP mDNSResponder
```

执行之后，终于可以正常上外网了。链式代理也没问题，奥地利的伪装 ISP IP 也正常工作。

写到这里，我能感觉到自己很累。不是那种做完正事之后的累，而是被前置条件消耗掉的累。明明只是想在图书馆坐下来工作，却先被网络配置折腾了两个小时。

但这也是现实。很多时候，真正的工作开始之前，要先处理一堆让人痛苦的环境问题。它们不光耗时间，也耗情绪和[[注意力管理|注意力]]。

## 明天是小西的生日

明天 **7月7日**，是我女朋友小西的 26 岁生日。

我今天本来最重要的任务，就是在图书馆给她写一封信。

说来惭愧，我到现在还是没有自己赚钱的能力。想给她买个像样的礼物都做不到，甚至现在我还有一万块负债。我还是在读大学，很多现实能力都还没有真正长出来。

这个事实很扎心。

它和[[../2025日记/财商]]有关，但又不只是钱的问题。它让我很直接地感受到：如果我没有赚钱能力，爱就会被现实压缩。不是说没钱就不能爱，而是很多想给对方的东西，会因为能力不够而做不到。

可是今天我也想提醒自己：没钱不等于什么都不能做。

我现在没有能力买很贵的礼物，但我至少还有能力写一封信。我可以用文字把我的心意、愧疚、爱、承诺和今天的状态放进去。

一封信不一定比礼物差。

它也是我此刻能给出的[[../2023日记/爱]]。

## 一号大哥的事

今天还收到了一号大哥的消息。他说自己可能要被劝退。

主要原因是注册考试次数太多，超过了 6 次限制；再加上延毕太久，学校正在讨论要不要给他一次面试机会。如果学校愿意给他面试，可能还有一点机会。

他说：

> 上次申请被拒了，因为学期次数太多。然后他们想跟我做 interview，结果我没收到邮件。

在我看来，这件事确实很符合他的性格。很多重要的事情，他好像都不是很上心。门牌号因为一些原因没有填对，导致没有收到学校邮件；匈牙利居留卡也准备回国再申请，最后就是自己给自己挖了很多坑。

我不知道该怎么评价这件事。

我当然会担心他，也会觉得可惜。但我现在更清楚的一点是：我只能先顾好我自己。在帮助别人之前，我要先看看自己的力量够不够。

这和[[../2024日记/课题分离]]、[[../2023日记/救世主心态]]有关。以前我可能很容易把别人的问题也背到自己身上，想去救，想去管，想去承担。但现在我知道，很多坑是别人长期选择的结果，不是我一句话、一次提醒、一次帮忙就能填平的。

我可以关心他，但不能替他过他的人生。

## 今天还是要回到自己的事上

今天折腾网络折腾到精疲力尽，又听到朋友可能被劝退的消息，再想到自己还没有赚钱能力、还有负债，我其实有一点被现实压住的感觉。

但我也看见了一点[[主体性]]：哪怕今天不是一个顺利开局，哪怕状态已经被网络配置消耗掉了，我还是可以决定接下来做什么。

现在最重要的事不是继续抱怨网络，也不是替一号大哥焦虑，更不是因为没钱就陷入羞愧里不动。

现在最重要的事，是去给小西写信。

我没有钱，但我还有心意。

我现在很累，但我还可以做一件我能做的事。

好了，我要去写信了。
